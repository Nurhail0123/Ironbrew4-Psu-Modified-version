Layers of protection for your Lua code.

Open workspace
01

Virtualization

Your script is compiled into custom bytecode designed for the obfuscator’s private virtual machine, rather than the standard Lua interpreter. The generated Lua wrapper runs that VM, keeping the original logic behind layers of bytecode and interpretation.

02

Control Flow Flattening

Control-flow transformations rearrange instruction blocks and introduce indirect branches, making the execution path harder to follow. Instead of exposing a clear sequence of operations, the protected script hides its structure behind virtual instructions and opaque predicates.

03

Anti-Tamper

Built-in integrity checks help detect changes to the protected script and its execution environment. When a check fails, the protection is designed to interrupt execution, making unauthorized modification and runtime inspection more difficult.

04

Aggressive Optimization

Minification removes unnecessary comments and whitespace, while optional compact output and super operators streamline the generated code and combine virtual instructions. These options can reduce output overhead; final size and execution speed depend on your script and selected protections.
